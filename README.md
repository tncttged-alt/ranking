# ランキングデータベース VER1.4


## VER1.4 記事自動作成ツール

カレントディレクトリの `input.txt` を読み、記事を自動生成します。

```bash
python3 tools/create_article.py
```

自動で行う処理:

1. `input.txt` のタイトル、概要、順位、キャラクター、評価軸、評価文を解析
2. `rankings/{URLスラッグ}/` を作成
3. 6キャラクターごとにページを自動分割
4. 最終ページだけに順位まとめを表示
5. `ranking-data.json` と読みやすい `ranking.js` を生成
6. `data/articles.json` に記事を自動登録
7. 記事一覧と人気記事表示の対象に追加

### 入力フォーマット

`【キャラ名】` と `【評価】` の間にある見出しは、すべて自由なステータスとして保存されます。

```text
【順位】
30

【キャラ名】
キャラクターA

【総合評価】
98点

【攻撃性能】
8点

【そのほかの評価軸】
48点

【評価】
評価の内容
```

`【URLスラッグ】` は半角英数字とハイフンを推奨します。省略時は `ranking-年月日-時分秒` 形式で自動生成します。`【タイトル読み】` を入力すると記事一覧の五十音順が正確になります。

### EXE化

Windowsで以下を実行します。

```text
exe-build-patch\build_exe.bat
```

生成先:

```text
dist\記事自動作成ツール.exe
```

EXEをプロジェクトルートに置き、同じカレントに `input.txt` を置いて実行してください。EXE化にはWindows、Python、インターネット接続が必要です。ビルド時にPyInstallerをインストールします。

### 入力前の注意

- 同じ順位を重複させない
- 順位は整数で入力する
- 各キャラクターに順位、キャラ名、評価を入力する
- 同じURLスラッグのフォルダがある場合は上書きしない
- 生成後にtitle、description、canonical、画像、広告リンクを確認する
